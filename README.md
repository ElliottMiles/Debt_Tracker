# Treasury Debt Tracker

A local, self-contained analysis of U.S. Treasury marketable debt — auction
history, maturity/rollover risk, interest cost, debt composition, and the
par yield curve — built from Treasury's own public data back to the 1980s
(1990 for the yield curve). The output is a single HTML file you open in
your browser; nothing is uploaded anywhere, and no internet connection is
needed to *view* the report once it's built (charts are rendered with a
copy of Chart.js bundled directly into the file).

## First-time setup

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

That creates a local virtual environment (`venv/`) and installs the three
packages the scripts need (`requests`, `openpyxl`, `pandas`) into it,
without touching anything else on your system.

## Running it

Every time you come back to this project, activate the venv first:

```bash
source venv/bin/activate
```

Then, to pull the latest data and rebuild the report:

```bash
python fetch_all.py
python build_report.py
```

Open `Debt_Report.html` in your browser to view it.

`fetch_all.py` just runs the two data-fetch scripts below in sequence — you
can also run either one on its own if you only need to refresh one data
source:

```bash
python fetch_auctions.py       # Treasury auction history -> Treasury_Auction_History.xlsx
python fetch_yield_curve.py    # Daily par yield curve rates -> Yield_Curve_History.csv
```

Both fetches are incremental: after the first run (which pulls full
history and takes longer), later runs only request what's new, so this is
cheap to re-run whenever you want current numbers.

`build_report.py` never touches the network — it only reads whatever is
currently in the two data files above and regenerates `Debt_Report.html`
from scratch each time. It's safe to re-run any time, including without
re-fetching first.

## What's in this folder

| File | What it is |
|---|---|
| `fetch_auctions.py` | Fetches Treasury auction history (Bills, Notes, Bonds, TIPS, FRNs, CMBs) into `Treasury_Auction_History.xlsx`. |
| `fetch_yield_curve.py` | Fetches the daily par yield curve (1 Month–30 Year) into `Yield_Curve_History.csv`. Accepts an optional start year on first run: `python fetch_yield_curve.py 1995` (defaults to 1990). |
| `fetch_all.py` | Convenience wrapper that runs both fetch scripts. Doesn't rebuild the report — that's still a separate, deliberate step. |
| `build_report.py` | Reads the two data files and writes `Debt_Report.html` from `report_template.html`. |
| `report_template.html` | The report's design/layout/chart code. Edited when the report's look or features change; not itself a data file. |
| `requirements.txt` | Python dependencies — see setup above. |

`Treasury_Auction_History.xlsx`, `Yield_Curve_History.csv`, and
`Debt_Report.html` are all generated output (regenerated by the scripts
above), so they're excluded from version control via `.gitignore` — don't
edit them by hand, since any changes would just be overwritten on the next
run.

## Notes on the data

The report covers **marketable, auctioned Treasury debt only** — it
excludes savings bonds, SLGS, and intragovernmental holdings, so totals
won't match the "total national debt" headline figure you see in the news.
This and a handful of other methodology notes (how floating-rate notes are
handled, what "refinancing cost impact" actually estimates, etc.) are
listed in full in the report itself, in the "Data & caveats" section at
the bottom.
